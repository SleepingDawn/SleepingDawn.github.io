# Dawn Signal

## Direction

A dark, editorial portfolio inspired by the moment just before sunrise. The page
should feel technical and deliberate without looking like a generic developer
dashboard.

## Visual language

- Background: deep navy with subtle grid lines and soft radial light.
- Accent colors: warm coral for the dawn, pale cyan for signals and links.
- Typography: large condensed-feeling headings paired with readable system text.
- Layout: asymmetric hero, numbered section labels, and responsive bento cards.
- Details: thin borders, pill labels, monospace metadata, and restrained motion.

## Interaction

- Smooth anchor navigation with a visible active section.
- A compact mobile navigation menu.
- Cards lift slightly on hover, but all information remains available without
  animation.
- Respect `prefers-reduced-motion`.

## Accessibility

- Maintain strong color contrast.
- Use semantic landmarks and heading order.
- Provide visible keyboard focus states and descriptive link labels.
- Keep all functionality available without JavaScript.
